# 🚀 Team Task Manager

A full-stack web application to manage daily tasks with authentication, deadlines, and real-time updates.

---

## 🌐 Live Demo

- 🔗 Frontend: https://team-task-manager.vercel.app  
- 🔗 Backend: https://team-task-manager-8mym.onrender.com  

---

## 🧠 Features

- 🔐 User Authentication (Signup & Login)
- ➕ Add Tasks
- ✏️ Update Task Status (Done/Pending)
- 🗑 Delete Tasks
- 📊 Task Statistics (Total, Completed, Overdue)
- 📅 Deadline Tracking
- 🌍 Fully Deployed Application

---

## 🛠 Tech Stack

### Frontend
- React.js
- Axios
- CSS (Custom Styling)

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Atlas)

### Authentication
- JWT (JSON Web Tokens)

### Deployment
- Frontend: Vercel
- Backend: Render
