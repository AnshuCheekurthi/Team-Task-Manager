# 🚀 Team Task Manager

A full-stack task management web application that allows users to create, update, and track tasks with authentication and deadline management.

---

## 🌐 Live Demo

- 🔗 Frontend: https://team-task-manager.vercel.app  
- 🔗 Backend: https://team-task-manager-8mym.onrender.com  

---

## 🧠 Features

- 🔐 User Authentication (Signup & Login using JWT)
- ➕ Add Tasks with deadlines
- ✏️ Update Task Status (Done / Pending)
- 🗑 Delete Tasks
- 📊 Dashboard with task statistics
- ⏰ Overdue task tracking
- 🌍 Fully deployed full-stack application

---

## 🛠 Tech Stack

### 💻 Frontend
- React.js
- Axios
- CSS (Custom Styling)

### ⚙️ Backend
- Node.js
- Express.js

### 🗄 Database
- MongoDB (Atlas)

### 🔐 Authentication
- JWT (JSON Web Tokens)

### 🚀 Deployment
- Frontend: Vercel
- Backend: Render
